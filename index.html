How it works

The DevOps Lifecycle

DevOps joins development and operations into one continuous loop, so ideas reach users quickly and safely.

01

Plan

Define the work, track tasks and agree on goals as a team.

02

Code

Write code and keep every change in version control with Git.

03

Build

Compile and package the application automatically on each change.

04

Test

Run automated tests early to catch bugs before they reach users.

05

Release

Prepare a stable, versioned build that is ready to go live.

06

Deploy

Push the release to servers or containers with repeatable steps.

07

Operate

Keep the application running smoothly in production.

08

Monitor

Watch logs and metrics, then feed what we learn back into planning.
